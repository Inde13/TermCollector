# Term Collector

🖥️ A cli-like collecting Python game.

⏳ The game is in very early development stage.

✨ [Contributions](CONTRIBUTING.md) and ideas are very well welcome.

## 🏛️ Dependencies

- pyyaml
- rich

## 🧩 How to play

Clone the repository and run
```
cd TermCollector
python main.py
```

if you don't have the dependency packages, run this first:
```
pip install rich pyyaml
```

✨ Boom! as simple as that.
