# Term Collector
🖥️ A cli-like collecting Python game.

⏳ The game is in very early development stage.

✨ Contributions and ideas are very well welcome.
(Please issue before sending a PR)

## 🏛️ Dependencies
- Pyyaml
- rich

## 🧩 How to play
Clone the repository and run the `main.py` file (in the game directory)

if you don't have the dependency packages, run
`pip install rich pyyaml`

✨ Boom! as simple as that.
