# Contributions

Hey! Thank you for contributing to the project (or at least thinking about it)!

Follow along to understand how to best collaborate with the game:

## General

How can you collaborate?

- 💻 Code
- 💡 Ideas
- 📃 Documentation
- 🐛 Bug fixing / issuing
- 🎮 Testing
- 🎯 Judging

And anything else you think will aggregate to the project!

It's preferable to post an issue before sending a PR.
That way we can discuss about the changes and coordinate for a better collaboration.

## 💻 Code

First, learn the [Code Structure](Docs/structure.md)

If you want to contribute with code, make sure to have this list in mind:

- Follow the PEP8 as much as possible
- Names and comments have to be in english
- Add documentation as frequently as possible
- ALWAYS add documentation for complex / messy code
- Have common sense

## 💡 Ideas

Anything that you think makes sense to the game is accepted
From new items to crazy features, if it's possible in the scope of the project, It is very well welcome!

## 📃 Documentation

As said before, documentation should be in English only.
You can add documentation anywhere you think is needed.

## 🐛 Bugs and testing

Found a bug or want to test the game? Feel free to issue any feedback. Every help is welcome and will be rewarded with VIFH (Virtual Imaginary Friendly Hugs 🫂)

## 🎯 Judging

"You want beef? Here's your place!"

If you think the codebase is bad, have an issue with some collaborator or for any reason have an opinion about the project, feel free to issue your judgement. I promise to take it in a constructive way (Unless...)

## That's it!

If you have any question, feel free to reach out.

Thank you for reading. (Here's one VIFH 🫂)
